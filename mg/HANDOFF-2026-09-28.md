## 7. Cautions

- **Never put text containing backticks inside a double-quoted shell string** (on 2026-09-27 it
  ran the first lines of five repo files as shell scripts). Use the Write/Edit tools, a script
  file, or a single-quoted heredoc.
- **Never `sed -i` a CRLF file in Git Bash**: it strips every CR. `chapter3.tex` and
  `main-reference.tex` are CRLF; edit them with the Edit tool or a Node script that splits and
  joins on `\r\n`, then check `file <path>` still says CRLF.
- **Never pipe a test run through `tail`**: finding 169's name was lost that way. Keep the whole
  output in a file.
- **The full lint gate takes 30–51 minutes** here; after a `src/plugins` change its plugin-SDK
  declaration step can hit its 300 s cap under load. Run it with nothing else heavy running.
- Other agents may work in this checkout at the same time. Snapshot `git status` first, edit line
  by line, and do not reformat whole files that already fail `oxfmt`. A worktree session applies
  its changes here as checked patches (`git apply --check` first); remove a worktree's
  `node_modules` with `rmdir /s /q`, never `rm -rf` (pnpm junctions point back to source).
- Keep a dated running log in `mg/` (Kinan asked for everything to be documented). Commit nothing
  without his word.
